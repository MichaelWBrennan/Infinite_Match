🛠️ CLI Tools

Use the Stripe CLI for local development and testing:

# Login to Stripe
stripe login

# Listen for webhooks
stripe listen --forward-to localhost:3000/api/stripe/webhook

# Test webhook events
stripe trigger payment_intent.succeeded

# View logs
stripe logs tail
