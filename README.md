# 🎮 **Evergreen Match-3** - Optimized Game Engine

[![Unity](https://img.shields.io/badge/Unity-2022.3.21f1-blue.svg)](https://unity3d.com/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

> **Optimized infinite content Match-3 game with hybrid RPG mechanics, real-time weather integration, and castle renovation meta-game.**

## 🚀 **Key Features**

### 🤖 **AI Infinite Content Engine**
- **Unlimited Levels**: AI generates infinite, personalized levels
- **Dynamic Difficulty**: Auto-adjusts to skill level
- **Personalized Events**: Weather-based events
- **Smart Power-ups**: AI creates custom power-ups

### 🏰 **Castle Renovation Meta-Game**
- **Build Your Dream Castle**: Renovate and decorate rooms
- **Earn Decorations**: Unlock furniture through gameplay
- **Room Challenges**: Complete renovation tasks
- **Social Showcase**: Share castle designs

### ⚔️ **Hybrid RPG Combat System**
- **8 Character Classes**: Warrior, Mage, Archer, Rogue, Paladin, Necromancer, Druid, Engineer
- **Skill Trees**: Unlock abilities that affect Match-3 gameplay
- **Equipment System**: Gear up with weapons and armor
- **Quest System**: Complete RPG-style missions

### 🌦️ **Real-Time Weather Integration**
- **Live Weather Effects**: Game visuals change based on real weather
- **Weather-Based Events**: Special events triggered by weather
- **Seasonal Content**: Dynamic content that adapts to seasons
- **Location-Aware**: Different experiences based on location

## 🎮 **How to Play**

### **Core Match-3**
1. **Match Tiles**: Create lines of 3+ matching colored tiles
2. **Build Combos**: Chain matches for massive score multipliers
3. **Use Power-ups**: Deploy special pieces strategically
4. **Complete Levels**: Reach target scores within move limits

### **RPG Progression**
1. **Choose Class**: Select character class and customize
2. **Level Up**: Gain experience through matches
3. **Unlock Skills**: Spend skill points on abilities
4. **Complete Quests**: Take on RPG-style missions

### **Castle Renovation**
1. **Earn Coins**: Use Match-3 winnings to purchase decorations
2. **Decorate Rooms**: Place furniture, change wallpapers
3. **Complete Tasks**: Finish room renovation challenges
4. **Unlock Areas**: Progress through castle to discover new rooms

## 🚀 **Quick Start**

```bash
# Clone and setup
git clone https://github.com/MichaelWBrennan/MobileGameSDK.git
cd MobileGameSDK
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
